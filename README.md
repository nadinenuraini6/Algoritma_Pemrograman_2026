File PDF diatas berisi Tugas 1 Algoritma dan Pemrograman dengan topik Pemrograman Menghitung Luas Tabung. Tugas ini menjelaskan cara membuat algoritma untuk menghitung volume tabung menggunakan rumus V = π × r² × t.Program menerima input berupa jari-jari (r) dan tinggi tabung (t), kemudian memvalidasi bahwa kedua nilai harus lebih dari 0. Jika input valid, program menghitung dan menampilkan hasil volume tabung, sedangkan jika tidak valid akan muncul pesan kesalahan. Selain itu, PDF juga memuat identifikasi Input-Proses-Output (IPO), pseudocode, flowchart, serta test case untuk menguji program menggunakan beberapa nilai jari-jari dan tinggi yang berbeda.
